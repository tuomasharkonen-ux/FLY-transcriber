Get started

Install in one line

Run this in your terminal

$ curl -LsSf https://raw.githubusercontent.com/tuomasharkonen-ux/FLY-transcriber/main/install.sh \ | sh

FLY transcribes with local AI models, so your audio never leaves your Mac and it works offline. That's why the install includes a one-time download of about 3 GB. No accounts or tokens.

🍎
Apple Silicon Mac · macOS 14.2+
💾
About 5 GB · for the speech models
🤖
An AI agent · such as Claude Code, optional
